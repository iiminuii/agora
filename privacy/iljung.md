## 2. 수집하는 정보

본 서비스는 다음 정보를 수집합니다.

| 항목 | 출처 | 목적 |
|---|---|---|
| 이메일 주소, 프로필 기본 정보 | Google / Microsoft / Apple 로그인 | 사용자 식별 및 계정 생성 |
| OAuth Access Token, Refresh Token | 각 캘린더 공급자 | 사용자 위임 범위 내에서 캘린더 이벤트 조회/생성/수정/삭제 |

본 서비스는 다음 정보를 수집하지 **않습니다**: 비밀번호(OAuth로만 로그인), 결제 정보, 위치 정보, 광고 식별자.

## 3. Google 사용자 데이터 사용 (Google API Services User Data Policy 준수)

본 서비스가 Google OAuth를 통해 접근하는 Google 사용자 데이터는 **Google API Services User Data Policy**(Limited Use 요구사항 포함)를 준수합니다. 구체적으로:

- Google Calendar 및 Tasks 데이터는 오직 **사용자가 명시적으로 연결한 다른 캘린더와의 동기화 목적으로만** 사용됩니다.
- 광고 목적으로 사용하거나, 제3자에게 판매·양도하지 않습니다.
- 사람이 직접 Google 사용자 데이터를 읽지 않습니다. 단, (a) 사용자 명시적 동의가 있거나 (b) 보안 목적 (c) 법적 의무 (d) 익명 집계 통계를 위한 경우는 예외입니다.
- 기계학습 모델 훈련에 사용하지 않습니다.

## 4. 저장 및 보호

- OAuth 토큰은 **애플리케이션 레벨에서 AES 암호화**된 상태로 데이터베이스에 저장됩니다.
- 데이터베이스 및 애플리케이션 서버는 TLS로 보호된 환경에서 운영됩니다.
- Refresh Token이 공급자로부터 무효화되면 즉시 재인증 플로우로 전환되며, 유효하지 않은 토큰으로 반복 호출하지 않습니다.

## 5. 제3자 제공 및 공유

본 서비스는 수집된 정보를 **제3자에게 제공·판매하지 않습니다.** 다음 경우에만 제한적으로 외부로 정보가 전달됩니다.

- 사용자가 직접 연결한 Google/Microsoft/Apple 캘린더 API로의 이벤트 생성/수정 요청 (사용자가 의도한 동기화 동작)
- 법령에 따른 요청이 있는 경우

## 6. 보관 및 삭제

- 사용자가 계정 삭제 또는 특정 캘린더 연결 해제를 요청하면, 해당 사용자의 OAuth 토큰과 동기화 매핑 정보는 **지체 없이 삭제**됩니다.
- 삭제 요청은 위 문의처 이메일로 받습니다.
- 원본 외부 캘린더(Google/Microsoft/Apple)의 이벤트 자체는 본 서비스 삭제와 무관하며, 각 공급자에서 별도로 관리해주세요.
